# Loadable families
Drop family files here; they auto-install on app start (js/families-loader).
- <id>.json  — { id, label, kind: "door"|"window", types: [{name,width,height,sill}], obj: "<OBJ mesh text>" }
- <id>.obj   — raw OBJ next to a matching <id>.json (use "objFile": "<id>.obj" instead of inline obj)
Get OBJ meshes from: sweethome3d.com/free-3-models, sketchfab (CC0 filter), free3d.com/3d-models/obj-door
