# Component credits

These six models came out of IngeTrazo's offline component bundle, which
sources them from the **Sweet Home 3D** furniture libraries
(`tools/extract-igz.js` performs the extraction and records provenance).
Each keeps its original license — the app's MIT code is unaffected, but the
models themselves must carry their terms when distributed.

**Changes from the originals** (CC BY 4.0 §3(a)): repackaged from the
`.igz` bundle into this app's JSON component format, XY-centered on the
footprint, coordinates rounded to 10 µm. No geometry or color modifications.

`arbol.igz` (Free Art License 1.3 — copyleft, incompatible with this
app's terms) and the author's personal face-me portraits (his own artwork).
